Open data

Every odds table we have collected, published as CSV with the date it was collected. Check our arithmetic, redo it differently, or use it in your own work.

We publish the raw data because a rating is only worth as much as the numbers behind it. Each file records the odds exactly as the platform displayed them on the collection date. Platforms do change their odds, so dated snapshots also let us show what changed and when.

Format

Both files use the same columns: platform, category, pack_name, pack_price, tier_min, tier_max, odds_pct, one row per value tier. The Courtyard file additionally carries a row per pack in the form EV,[pack_name],[value] holding the expected value Courtyard publishes for that pack.
