# PackEV — packev.xyz

A static site. No build step, no dependencies, no framework. Every table is
rendered into the HTML at build time, so crawlers that don't run JavaScript —
including most AI crawlers — still see all the numbers.

41 pages covering 24 platforms.

## Deploy

Push to the repo; Vercel redeploys automatically. Framework preset **Other**,
no build command, no output directory.

`vercel.json` sets clean URLs, caches the stylesheet, and sends
`X-Robots-Tag: noindex` to the `*.vercel.app` host so the preview URL never
competes with packev.xyz in search.

## After each deploy

Submit new or changed URLs to IndexNow (Bing, Yandex, Seznam, Naver — Google
does not participate):

```
python3 indexnow.py
```

For Google, use Search Console: submit `/sitemap.xml` once, then URL
Inspection → Request Indexing for individual priority pages.

## Launch checklist

- [x] Real domain in `BASE_URL` (layout.py) — feeds canonicals, sitemap, JSON-LD
- [x] Google tag `G-BCTDNF4LCD` on all pages (`GA_ID` in layout.py)
- [x] IndexNow key file served at the site root
- [x] Packz referral link, disclosed, `rel="sponsored nofollow noopener"`
- [ ] Submit sitemap in Google Search Console
- [ ] Verify in Bing Webmaster Tools
- [ ] Filter internal traffic in GA4 (Admin → Data Streams → Configure tag
      settings → Define internal traffic)
- [ ] Email the platforms their figures and invite corrections

## Rebuilding

Generated by three files kept beside the output:

- `data.py` — loads the odds data and computes every figure
- `layout.py` — page shell, meta tags, JSON-LD, `BASE_URL`, `GA_ID`
- `build.py` — page content; writes `site/`

```
python3 build.py
```

No third-party packages required. To add a platform: add its data in `data.py`,
add a page function in `build.py`, register it in `main()`, and add it to the
transparency ranking on the home page.

Affiliate links live in the `AFFILIATE` dict near the top of `build.py`. Each
entry states what the reader gets *and* what we get; the renderer shows both.
Leave a platform out entirely rather than linking without terms.

## A note on the numbers

Every expected value on this site comes from the platforms' own published odds
and, in most cases, their own card valuations. The exception is Clutch Packs,
which publishes observed on-chain results. Nothing has been checked against
real sold prices yet. The pages say so, in those words, in a callout.

Do not remove those caveats before the verification work is done — they are
the reason the numbers are worth trusting, and they're the only thing that
distinguishes this site from the affiliate content farms already ranking for
these terms.
